☸ Đi chùa Việt Nam

Game đi chùa 3D chạy trên web: tạo nhân vật Phật tử, viếng Chùa Trấn Quốc, thắp hương, vái Phật, tham quan và nhận giấy chứng nhận. Gói này đã có sẵn Dockerfile và compose.yaml để chạy trên Ubuntu 24.04.

Tải .tar.gz (Ubuntu) Tải .zip (Windows) SHA256SUMS.txt

Chạy trên Ubuntu 24.04 bằng Docker

1. Cài Docker (bỏ qua nếu đã có):

sudo apt update
sudo apt install -y ca-certificates curl
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] https://download.docker.com/linux/ubuntu $(. /etc/os-release && echo $VERSION_CODENAME) stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
sudo usermod -aG docker $USER   # đăng xuất rồi đăng nhập lại

2. Tải và giải nén mã nguồn:

cd ~
curl -fLO https://view.hangocthanh.io.vn/…/di-chua-viet-nam/di-chua-viet-nam.tar.gz
tar -xzf di-chua-viet-nam.tar.gz
cd di-chua-online

3. Build và chạy:

docker compose up -d --build
docker compose ps                    # chờ STATUS = healthy
curl http://localhost:3000/healthz   # {"ok":true}

4. Mở trình duyệt: http://IP_SERVER:3000 (mở cổng 3000 trên firewall/cloud nếu cần).

Dữ liệu tài khoản lưu trong Docker volume di-chua-data; docker compose down vẫn giữ dữ liệu, chỉ docker compose down -v mới xoá.

Chạy trên Windows (không cần Docker)

cd di-chua-online
npm install
npm test        # # pass 12, # fail 0
npm start       # mở http://localhost:3000

Cần Node.js 22 LTS từ nodejs.org.
