Năm task TDD, hai repository, một nguyên tắc an toàn: thiếu bằng chứng thì giữ nguyên catalog.

Kiến trúc

Plugin c-shared stateless chạy response.intercept_after, đọc host.auth.list và host.auth.models, rồi lọc hai catalog OpenAI/Codex. Core registry, scheduler, credential state và fallback không thay đổi.

/v1/models → catalog core → plugin callbacks → ownership + runtime state → filter known all-unavailable models → catalog response

Năm deliverable

01

Availability policy

Controlled-clock tests cho active, disabled, future/expired cooldown, unknown ownership và multi-account.

02

Catalog filter

Giữ order và mọi field của OpenAI data[*].id và Codex models[*].slug; malformed/unsupported fail-open.

03

Native ABI plugin

C bridge, lifecycle, fake-host integration, race test, c-shared artifact và image packaging.

04

Deploy integration

Config priority 90, copy artifact từ pinned image vào persistent plugin mount, bắt buộc registration log.

05

Production evidence

Normal → High → XHigh review, CI, immutable image, deploy, model-list diagnostics, completion smoke và rollback.

Ràng buộc

  • Không sửa core registry/scheduler.
  • Không secret, database, timer, poller, probe hoặc port mới.
  • Không suy luận per-model cooldown vì ABI chưa expose ModelStates.
  • Không deploy floating image tag.
  • Plugin lỗi phải trả catalog gốc.

Cách thực thi

Subagent-driven

Khuyến nghị. Mỗi task có implementer và reviewer riêng, sau đó whole-branch review. Phù hợp vì lỗi catalog có thể ẩn nhầm toàn bộ model và công việc trải qua hai repository.

Native

Tôi triển khai tuần tự trong session, rồi một reviewer độc lập review toàn branch. Nhanh và ít context hơn, nhưng review độc lập chỉ đến cuối.
