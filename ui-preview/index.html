Mục tiêu

Plugin cooldown-model-filter chỉ sửa response danh sách model. Nó không khóa tài khoản, không thay đổi cooldown, không chọn credential, không probe quota và không thay đổi đường thực thi request.

Giữ model

Còn ít nhất một credential khỏe, hoặc ownership/state chưa đủ chắc chắn.

Ẩn model

Mọi credential đã biết của model đều disabled hoặc unavailable ở thời điểm hiện tại.

Luồng xử lý

1. CatalogCPA tạo response /v1/models.
2. Runtime stateGọi host.auth.list.
3. OwnershipGọi host.auth.models.
4. FilterGhép credential ID và lọc.
5. RecoveryRefresh sau deadline tự hiện lại.

Không cron, database hoặc timer nền. Mỗi lần client tải catalog, plugin tính lại từ host state hiện tại.

Chính sách lọc

usable = !disabled && ( !unavailable || (next_retry_after != zero && next_retry_after <= now) ) hide(model) = known_owners(model) > 0 && every owner is unusable
  • unavailable=true nhưng không có deadline: coi là chưa thể tự phục hồi.
  • Model không map được tới credential: luôn giữ, không đoán.
  • Static plugin model không có ownership credential: luôn giữ.
  • Hỗ trợ OpenAI data[*].id và Codex client models[*].slug.

Fail-open

Mọi lỗi callback, JSON, join identity hoặc shape không hỗ trợ đều trả nguyên catalog. Plugin không được làm mất model khi thiếu bằng chứng.

X-CPA-Cooldown-Model-Filter: applied | bypassed X-CPA-Cooldown-Models-Hidden: <count>

Kết quả lọc rỗng không chứng minh đầy đủ ownership/state sẽ bị hủy và trả body gốc.
