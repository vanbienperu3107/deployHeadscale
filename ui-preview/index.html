01 / architecture

Public ingress, private runtime.

OpenCode v2 chạy trong container độc lập, chỉ được Caddy gọi qua Docker network edge. Tailscale sidecar cung cấp Tailnet netns; OpenCode không có Docker socket, host mount hay capability TUN.

Browser HTTPS: opencode2.hangocthanh.io.vn ↓ edge-nginx :443 -- SNI passthrough --> Caddy :8447 ↓ PROXY protocol + TLS-ALPN + JSON access log ↓ opencode2 :4096 -- workspace/state --> CLIProxy + Internet + Tailnet SSH

02 / auth and automatic permissions

Basic Auth ở biên, mọi tool tự động ở bên trong.

  1. DNS preflight. opencode2.hangocthanh.io.vn phải trỏ đúng VPN4 trước khi deploy edge.
  2. SNI route riêng. Nginx chuyển domain qua listener loopback, gắn PROXY protocol để Caddy thấy IP thật.
  3. TLS-ALPN. Caddy xin certificate qua SNI passthrough; port 80 vẫn dành cho DERP.
  4. Server authentication. Mọi API và pairing flow yêu cầu OpenCode HTTP Basic Auth.
  5. Permission wildcard. Rules v2 action: *, resource: *, effect: allow cho mọi shell, edit, network, MCP và plugin tool.
  6. Rate protection. fail2ban ban IP sau 5 phản hồi 401 trong 10 phút.

03 / isolation invariants

Agent được làm việc, không được chạm Docker hoặc host.

Không Docker socketKhông privileged mode, host networking hay Linux capability bổ sung.
Không host filesystemChỉ hai named volumes workspace và state được cấp cho container.
Không port backend publicCaddy là đường vào duy nhất; service chỉ nằm trong network edge.
Không secret trong GitCredential chỉ ở GitHub Secrets và file VPS mode 0600.
Có Internet thậtAgent clone Git, cài dependency, gọi provider và chạy mọi tool không cần prompt.
Không ảnh hưởng v1OpenCode v2 có Caddy listener, access log và fail2ban jail riêng.

04 / persistence and operations

Deploy lại không làm mất workspace, session hay Tailnet identity.

opencode2_workspace giữ repository/artifact người dùng tạo. opencode2_state giữ SQLite database, session, config và auth state. Redeploy chỉ recreate container và không dùng -v.

OpenCode state và Tailscale state dùng volume riêng. Sidecar join Headscale bằng auth key riêng, hostname opencode2. Headscale ACL allow all theo yêu cầu; SSH dùng user/key riêng, known_hosts pinning và không dùng root.
